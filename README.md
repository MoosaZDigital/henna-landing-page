# Henna Studio: Landing Page

A landing page for a henna artist in Edmonton, built while learning web development. I created this project to practise building a website and adding interactive features.

All business details and content are sample/placeholder information.

## Live Site

[View the live website](https://moosazdigital.github.io/henna-landing-page/)

## Features

- A hero banner, service cards, and a photo gallery.
- An FAQ section built using a JavaScript array. Opening one question closes the others.
- Live Edmonton temperature from a weather API, with loading and error messages.
- Email and phone contact links.
- A demo contact form.
- A responsive layout that works on phones.
- The year in the footer updates automatically.

## Built With

- HTML, CSS, and JavaScript (no frameworks)
- [Open-Meteo](https://open-meteo.com/) weather API
- [Vite](https://vite.dev/) for the local development server
- Git and GitHub Pages for version control and hosting

## Run It Locally

You need [Node.js](https://nodejs.org/) installed to run this project on your computer.

 Run these commands in your terminal:

```bash
git clone https://github.com/MoosaZDigital/henna-landing-page.git
cd henna-landing-page
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.
